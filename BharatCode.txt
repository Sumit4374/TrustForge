BharatCode is the primary live model provider. The dedicated Java adapter is:
server/src/main/java/com/sumit/trustforge/ai/BharatCodeGateway.java

AI operations: scenario generation, model-backed agent decisions in a bounded synthetic tool loop, and supplementary remediation/report recommendations.
